# Glossary

- **LNGX** — the native token asset.
- **Item** — a distinct on-chain asset (`genesis_hash`, `amount`, `metadata`).
- **DRUID** — the identifier tying the two halves of a two-way swap together.
- **valence** — the off-chain relay that carries two-way payment offers between parties.
- **UTXO** — unspent transaction output; the balance model.
- **genesis_hash** — the id minted when an item asset is created.
